# WireWise

A modern React web application for calculating aluminium wire production costs, material usage, waste percentage, and profit.

## Overview

WireWise is designed for aluminium wire manufacturing workflows. It helps estimate the weight of produced wire from its dimensions, calculate material costs, account for production waste, and estimate overall profit.

## Features

- Calculate wire weight from diameter and length
- Material cost estimator
- Waste percentage calculator
- Revenue and profit analysis
- Clean, responsive industrial dashboard
- Built with React + TypeScript

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Getting Started

```bash
npm install
npm run dev
```
